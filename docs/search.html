🔎 Search & Command Palette

Find anything instantly with Ctrl+K

Opening the Command Palette

Press Ctrl+K on Windows or Linux, or Cmd+K on Mac, from anywhere in LogHue. It opens a search box over whatever you're doing, so you never have to navigate through menus to find something.

What It Searches

A single search covers everything at once, across your personal items and anything you're part of in a workspace:

  • Tasks - personal and workspace tasks
  • Notes - personal and imported notes
  • Workspaces - any workspace you belong to

Typing a name jumps straight to that item. There's no need to know which section it lives in first.

Shortcuts

A few typed phrases act as shortcuts to list everything of a given type at once:

all tasks

Every task, personal and shared

all notes

Every note, personal and shared

all workspaces

Every workspace you're in
