📋 Team Tasks & Logs

How tasks behave once they're shared in a workspace

Creating Tasks in a Workspace

A workspace task can start two ways: created directly in the workspace, or duplicated in from your personal task list. See Tasks & Notes for how duplication works from the personal side. To create one directly:

  • Go to your workspace
  • Click "New Task"
  • Enter a clear title
  • Add a description
  • Assign it to a team member
  • Click "Create"

Tasks can be assigned to specific members.

Task States and Logging Progress

For simplicity, tasks move through two states as work progresses:

In Progress

Newly created and currently being worked on

Completed

Finished, finalized and archived

Anyone working on a task can post a log: a short update about progress made, or anything worth sharing about the task.

  • Click View Task in the workspace task
  • Below the Task view page, enter what you accomplished in the input field
  • Click "Submit Log"

A log can include your own sense of whether the task is done, but that's informational only, meant to help whoever's reviewing know where things stand. It doesn't change the task's actual state. Only an Owner or Admin can mark a task Completed; Members can log updates but not close the task themselves.

Logs are timestamped automatically and visible to all workspace members.

Discussions

Start conversations with your team:

General Discussions

Start a discussion about anything related to the workspace.

Task-Linked Discussions

Start a discussion related to a task for focused conversation.

Comments & Replies

Comment on discussions and reply to others to collaborate.

Notes in a Workspace

Notes start out personal, but any note can be imported into a workspace to share it with the team. The original stays in your personal notes untouched. See Tasks & Notes for creating and exporting notes.

Histories

Keep your workspace clean by closing completed tasks:

  • Closed tasks are hidden from the main view
  • All data is preserved
  • Closed tasks are visible in the task history section
  • You can restore closed tasks anytime

To close: Open a task → click "Mark as completed". To view archived: go to Tasks History in the sidebar.
