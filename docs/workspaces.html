🏢 Workspaces

Everything about creating and managing workspaces in LogHue.

What is a Workspace?

A LogHue workspace is a shared space for organizing projects, tasks, notes, discussions, and team activity. Workspaces are optional: your tasks and notes can remain personal until you choose to share them with a team.

  • Tasks - work items shared with the team
  • Logs - progress updates team members post on shared tasks
  • Discussions - conversations and comments
  • Activities - overview of what happened in the workspace
  • Members - people who work in the workspace

Duplicating a task or importing a note into a workspace never removes it from your personal list. You end up with two independent copies that you can manage separately. See Tasks & Notes for how that works from the personal side.

Tip: Create separate workspaces for different projects, teams, or departments to keep things organized.

Creating a Workspace

Creating a workspace is simple:

  • On any main page sidebar, click the "+ New Workspace" button.
  • Enter a name for your workspace
  • Add a description (optional but helpful)
  • Click "Create Workspace"

Workspace creation limits vary by plan. The Team plan offers unlimited workspaces.

Workspace Settings

Owners and Admins can manage workspace settings:

  • Edit - Edit the workspace name and description
  • API Keys - Create and manage API keys for integrations
  • Archive - Archive the workspace when done
  • Transfer Ownership - Only owner can give ownership to another admin

Access settings by clicking the Settings button in your workspace.

Archiving Workspaces

When a project ends, you can archive the workspace instead of deleting it. Archived workspaces:

  • Are hidden from your main dashboard and "all workspaces" page
  • Preserve all tasks, logs, and discussions
  • Can be restored anytime
  • Don't count against any limits

To archive: Go to Settings → click "Archive Workspace".

Transferring Ownership

If you need to step away from a workspace, you can transfer ownership to another admin:

  • Go to Settings → Transfer Ownership
  • Find the admin you want to transfer to
  • Click "Transfer Ownership"
  • Confirm the transfer

Only workspace owners can transfer ownership.
