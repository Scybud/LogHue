📝 Tasks & Notes

Your personal tasks and notes, before anyone else sees them

Personal by Default

Every task and every note you create in LogHue belongs to you first. Nothing is shared automatically, and there's no workspace required to use either. Think of your personal list as your own working space, separate from any team.

Tasks

Tasks are checkable items with a deadline, built for planning your own day. You can use them inside LogHue or on their own at tasks.loghue.com with the same account.

1 Create a Task

Click "+ Create Task" at the top of the task page. Give it a title, set a deadline date and time, and add a description if you like.

2 Mark It Done

Check a task off whenever you finish it. Done tasks move into a separate, collapsible section, so your active list stays focused on what's left.

3 Edit, Undo, Delete, or Keep It

Use the icons on a task card to edit it, duplicate it to a workspace, or delete it. A done task can be unmarked back to active or simply left as a record. There's no time limit on any of these.

Calendar View

Switch from the list to the calendar to see your tasks laid out in time. The list stays the default, and both views show the same tasks.

  • Choose Year, Month, Week, Day, or Hour view. Week is the default
  • A live clock and a moving "now" line show where you are in the day
  • Overdue tasks that aren't done turn red
  • Done tasks are greyed out and struck through
  • Tasks due at similar times sit side by side, so every one stays visible and clickable

The calendar currently shows your personal tasks.

Start and End Time

Open the settings icon in the task form to give a task a start and end time. This lets you see how much free time you have around your tasks directly on the calendar. It works for any task, recurring or not.

Recurring Tasks

Mark a task as recurring to have it repeat daily at the time you set.

  • Every occurrence is its own entry, so checking one off only affects that day
  • The original recurring task stays in its own collapsed section, separate from your day to day list
  • Every occurrence uses the same start and end time

Reminders

LogHue reminds you before a task is due, 30 minutes and 5 minutes before the deadline by email. Turn on push notifications in Settings → Notifications to get them on your device too.

For recurring tasks, choose which days you want reminders: every day, weekdays, weekends, or specific days like Monday. If you don't change anything, you get reminders every day. The task itself still repeats daily, only the reminders follow your chosen days.

Note: Workspace tasks with a deadline send reminders too. See Team Tasks & Logs.

Sharing a Task to a Workspace

If a task becomes something a team needs to see, you can duplicate it into a workspace. The original stays in your personal list exactly as it was, untouched. You end up with two independent copies, so you can delete either one without affecting the other.

Note: Once a task is duplicated into a workspace, it follows workspace rules there, including who can mark it complete. See Team Tasks & Logs for how that works.

Notes

Notes are standalone by default, separate from tasks, and built for anything you want to keep handy: meeting summaries, ideas, references, or anything in between. You can use them inside LogHue or on their own at notes.loghue.com with the same account.

Note Types

Click "+ Create" on the notes page and choose what to make:

Text Note

A rich text editor with fonts, bold, italic, underline, links, text color, highlights, lists, checklists, and alignment. Your note saves as you type.

Sketch

A free drawing canvas with pen and eraser tools, for diagrams and quick thinking you can't type.

Table

A standalone table note. You can also add tables inside a text note alongside your writing.

Folders

Choose New Folder to group related notes. Notes inside a folder are listed under it, and the folder can be collapsed. Notes without a folder stay in the main list. Use Add to folder or Remove from folder in a note's menu to move it.

Linking Notes to Tasks

Link a note to tasks when you want them connected. The editor shows how many tasks a note is linked to.

Exporting

  • Text notes: TXT, MD, HTML, PDF, or DOCX
  • Sketches: PNG image
  • Tables: HTML or PDF

Note: Free accounts export TXT and MD. PDF, DOCX, and HTML export are part of the Pro plan. See loghue.com/pricing.

Sharing a Note Publicly

Notes are private until you decide otherwise. To share one, open its menu and click Share publicly. LogHue creates a link, and anyone who has the link can view that note.

  • Copy public link: copy the link to send it
  • Show my name: choose whether the page shows who wrote it
  • Regenerate link: create a new link, which stops the old one from working
  • Stop sharing: turn the link off and make the note private again

Anyone with the link can read the note, so don't share notes that contain private information. If a link gets out, use Regenerate link or Stop sharing.

Sharing with a Team

Import a note into a workspace when you want to share it with a team. Like tasks, importing doesn't remove it from your personal notes. It becomes visible in both places independently. In a workspace, any member can view or download a note, but only its creator can delete it.
